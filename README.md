# Sentinel‑2 Agriculture Systematic Review

**Data and code for:**  
*Monitoring Phenological Stages and Detection of Agricultural Operations Using Sentinel‑2 Time Series: A Systematic Review*  
(Remote Sensing of Environment, 2026)

---

## 📌 Overview
This repository contains all data, analytical reports, and code supporting the systematic review of Sentinel‑2‑based methods for detecting crop phenology and agricultural operations (tillage, sowing, irrigation, harvest).
